# leila-evalboard · 大模型译文审校可靠性评测看板

基于人机一致性，而不是模型自报置信度，判断不同审校场景可以被授予多大的自动化权限。

## 看板内容

- **评测设计**：MQM 四维框架（术语一致性 / 准确性 / 本地化规范 / 受众适配性）× 四级严重度 × 三档内容风险
- **人机双评**：94 条双语语料中 15 条进入正式双评；3 款模型（GPT-4o / Claude / Gemini）生成 45 份译文，人工与 Qwen 独立评分，共 180 次判断
- **核心结论**：整体一致率 95%（Gwet's AC1 0.947）；术语一致性 × 高风险是唯一红灯格（11/18，61%）
- **分歧审查**：AI 无依据断言「官方译法」6 次被人工以外部证据纠回；AI 抓回人工漏检 3 次（外部证据改判）
- **产品策略**：12 格一致性矩阵 → 三级人工介入（100% 人工 / 10% 抽检 / 5% 抽检），离线推演人工复核量 28/180（15.5%）

## 数据口径

数据来自冻结的 Pilot 评测结果（2026-07 ~ 2026-08），页面不做实时计算；15.5% 为离线策略推演值，非线上实测。
